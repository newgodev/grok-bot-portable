```yaml
---

kind: rule
temporal: standing   # or event
valid_from: 2026-01-01T00:00:00+08:00

---
```

## Body shape (when → then)

1. **When** — trigger keywords / situation (generic).
2. **Then** — what to do / not do.
3. **Evidence** — optional quote or link to an event file under `events/`.

See `EXAMPLE-when-then-keyword-gate.md` for one public-safe skeleton.
