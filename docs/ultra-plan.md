# Ultra / plan — what helped (facts only)

This is **one chapter inside** `grok-bot-portable`, not a second repo.

## Helped-me (power-user fact)

**Using Ultra (US$200/mo, 50× Plus usage)** fits **heavy multi-agent / Automation** work: one shared **weekly** pool across Cursor, Grok Bot, and Grok apps, with headroom so a busy day does not wipe the month. Official docs recommend Ultra for power users running several agents or Automations.

What helped (public rules):

1. Treat Ultra as **capacity**, not unlimited — prefer included Cursor models; leave Auto Top-up off; set a monthly additional usage limit.
2. Grok Bot is on **Premium+**; Ultra is **50×** Plus vs Premium **4×** / Super **15×**.
3. Additional usage **credits are separate** from the plan fee.
